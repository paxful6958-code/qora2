# Qora Trading Platform

An AI-Powered Multi-Asset Trading Web Platform built with React, Vite, and Tailwind CSS.

## Features
- AI-assisted market analysis
- Multi-asset support (Forex, Crypto, Stocks, Commodities, Indices)
- Real-time trading dashboard architecture
- Support for multiple payment methods (M-Pesa, Cards, Crypto)
